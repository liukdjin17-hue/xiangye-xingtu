# 乡野星图 · 县乡青少年职业探索工作台

> 2026"联通杯"AI 应用创新大赛 · 县乡教育赋能赛道参赛作品（队伍：拾光职引）

一套**零依赖、可离线、结论由代码算出**的县乡中学生生涯探索工具：纯静态网页，不装 App、不注册、不联网，也能完整做完一次职业探索。

## 功能

- **霍兰德职业兴趣测评**：60 题，六维各 10 题（活动 4 / 能力 3 / 职业 3），带补答闸门，缺答不放行，结果可复现
- **职业地图与画像**：29 个县域可触达职业（护士、幼师、电工、数控、无人机飞手、乡村规划……），59 条口语别名（"种地"→"农业技术员"、"码农"→"程序员"）
- **分阶探索任务**：14 项任务，覆盖小学五年级到中职三年级共 11 个年级
- **小星星 AI 助手**：三层降级链——本地知识库（58 条）→ 用户自配大模型（DeepSeek）→ 本地规则兜底；断网 / 无 Key / 接口故障都不白屏，模型只组织语言，不参与评分
- **教师端**：独立页面 `teacher.html`，不读取学生数据
- **隐私本地化**：无账号、无云同步，记录只存本机 localStorage

## 运行

零依赖、零构建，任选一种：

```bash
# 方式一：直接双击 index.html（浏览器打开即用）

# 方式二：本地起个静态服务（Service Worker 离线缓存需要 http 环境）
python -m http.server 8080 -d app
# 浏览器打开 http://localhost:8080
```

安装为 PWA：浏览器访问后选择"安装应用"即可；安卓可用 WebView 套壳打包（约 146 KB，不申请联网权限）。

## 测试

```bash
node tests/e2e.js        # 其余 e2e-v*.js、qa-*.js 同理
```

共 185 项自动化断言，覆盖测评算法、别名映射、降级链与页面渲染。

## 目录结构

```
├── app/               # 应用本体（纯前端静态站点）
│   ├── index.html     # 学生端入口
│   ├── teacher.html   # 教师端入口
│   ├── manifest.json  # PWA 配置
│   ├── sw.js          # Service Worker（离线缓存）
│   └── assets/
│       ├── data.js    # 题库 / 职业库 / 任务库
│       ├── app.js     # 学生端主逻辑
│       ├── star.js    # AI 助手（知识库 + 降级链）
│       ├── teacher.js # 教师端逻辑
│       └── tour.js    # 新手引导
├── scripts/           # 构建脚本（桌面启动器、单页排版修复等）
├── tests/             # 自动化测试
```

## 技术要点

- 纯 HTML/CSS/JS，14 个文件约 5300 行，0 第三方依赖、0 构建步骤
- 测评算法无随机数、无模型介入，同一答卷在任何设备得到同一结果
- 大模型接口由用户在设置页自行填写地址与 API Key，核心功能不依赖任何外部服务
